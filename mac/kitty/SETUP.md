# kitty colours (macOS)

Catppuccin Frappé theme, the same one the Mac had before fish. Linux doesn't
use this file: its colours come from Noctalia (see [`shared/kitty/SETUP.md`](../../shared/kitty/SETUP.md)).

| Repo | Destination |
|---|---|
| `colors.conf` | `~/.config/kitty/colors.conf` |
| `macos.conf` | `~/.config/kitty/macos.conf` |

`macos.conf` sets the remote-control socket to a path, because macOS has no
abstract sockets. See [`shared/kitty/SETUP.md`](../../shared/kitty/SETUP.md).
