# Hyprland config

`~/.config/hypr`, owned by this repo since the switch from caelestia's shell to
Noctalia (2026-10-08). It started as caelestia's tree at revision `1ee7a98`;
the untouched original is in `linux/caelestia/hypr-reference`, with notes on
what needs caelestia.

**Never run `caelestia update` again.** It rewrites `~/.config/hypr` with
caelestia's files and would undo the changes below.

## Files

Every file is in `manifest.tsv` with its destination under `~/.config/hypr`.

| Repo | What |
|---|---|
| `hyprland.lua` | entry point: loads the modules, then the override layers (below) |
| `variables.lua` | key names, apps, colours read by the modules; `hypr-vars.lua` overrides values |
| `hyprland/*.lua` | env, general, input, misc, animations, decoration, group, autostart (`execs.lua`), rules, gestures, binds |
| `hypr-vars.lua`, `hypr-user.lua` | the override layers (below); documented in `linux/caelestia/SETUP.md` |
| `utils/functions.lua` | helpers the binds and autostart use (pop-up workspaces, picture-in-picture) |
| `animations/` | animation presets, one picked by name in `hyprland/animations.lua` (below) |
| `scheme/default.lua` | fallback colours, copied to `scheme/current.lua` when that is missing |

`hyprland-gui.lua` (HyprMod, `linux/hyprmod`) and `hyprsunset.conf`
(`linux/hyprsunset`) also live in `~/.config/hypr` but belong to those packages.
`scheme/current.lua` (the colour file that borders, group bars and the background read)
is generated by a Noctalia template from the wallpaper palette
(`linux/noctalia`), so it isn't tracked. `scheme/current.conf` is a leftover
caelestia generated; nothing reads it.

## Load order

`hyprland.lua` loads `hypr-vars.lua`, the `hyprland/*.lua` modules,
`hypr-user.lua` (window mode, per-monitor workspaces), then HyprMod's
`hyprland-gui.lua`, all from `~/.config/hypr`. Until 2026-10-09 the two
override files lived in `~/.config/caelestia`.

## Changes from caelestia's original

- **Autostart** (`hyprland/execs.lua`): starts Noctalia
  (`uwsm app -- noctalia`) instead of `caelestia shell -d`. The gammastep and
  geoclue lines are gone: neither was installed, and the night light is
  hyprsunset.
- **Shell keys** (`hyprland/keybinds.lua`) call `noctalia msg …` instead of
  caelestia's shell. See `linux/noctalia/SETUP.md` for the list. caelestia's
  recording keys, "show all panels", "restart and lock" and "delete clipboard
  entry" have no Noctalia counterpart and are removed. Also removed: the
  ydotool "paste latest" key and the cliphist watchers (Noctalia keeps its own
  clipboard history), the duplicate region-screenshot and colour-picker keys
  (Super+Shift+S and HyprMod's Super+Shift+P stay), Super+P pin (HyprMod's
  Super+Shift+F pins), the test-notification key, and the autostart lines for
  a second gnome-keyring and mpris-proxy.
- **Environment:** uwsm gives apps started by systemd or D-Bus the variables
  in `~/.config/uwsm/env` and `env-hyprland` (`linux/uwsm`), not those in
  `hyprland/env.lua`. Change both when a variable changes.
- **Rules** (`hyprland/rules.lua`): Noctalia's recommended blur for its bar,
  panels and notifications, a floating settings window, and no Hyprland
  animation on any Noctalia layer. caelestia's slide-in for layers otherwise
  made the screenshot overlay drop in from the top. Hyprland matches the whole
  namespace, so the pattern is `^noctalia-.*$`, not `^noctalia-`.
- **Animations** (`hyprland/animations.lua`): picks a preset by name from
  `animations/`. `caelestia.lua` is caelestia's original set and is the one in
  use (quick window open and close, smooth workspace slides, vertical
  slide-fade for pop-up workspaces). The others are HyDE's presets
  (HyDE-Project/HyDE, `Configs/.local/share/hypr/lua/animations/`, GPL-3.0),
  copied unchanged at HyDE commit `fa2fd57a`, with HyDE's GPL-3.0 licence as
  `animations/LICENSE`; they only call `hl.curve` and `hl.animation`, and most
  scale their speeds by `hyde.config.anim.duration_scale`, which the picker sets to 1.
  HyDE's `classic` was tried and dropped: slower window open/close, faster
  workspace switches, sideways pop-ups.
