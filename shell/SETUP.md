# shell

zsh + oh-my-zsh + powerlevel10k, with the modern-CLI aliases and PATH setup.
This is the package everything else assumes.

## Files

| Repo | Destination |
|---|---|
| `zshrc` | `~/.zshrc` |
| `zprofile` | `~/.zprofile` |
| `zshenv` | `~/.zshenv` |
| `p10k.zsh` | `~/.p10k.zsh` |
| `nanorc` | `~/.nanorc` |

All five are safe to symlink. `p10k.zsh` is generated by `p10k configure` but
never touched afterwards, so linking is fine.

## Dependencies

### Base

| | macOS | Debian/Ubuntu |
|---|---|---|
| zsh | preinstalled | `apt install zsh` + `chsh -s $(which zsh)` |
| oh-my-zsh | `sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"` | same |
| powerlevel10k | `git clone --depth=1 https://github.com/romkatv/powerlevel10k.git ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/themes/powerlevel10k` | same |

Run the oh-my-zsh installer with `--keep-zshrc`, or it overwrites `~/.zshrc` and
you'll have to relink.

### zsh plugins

`zshrc` looks for each plugin in `$HOMEBREW_PREFIX/share`, then `/usr/share`,
then `/usr/share/zsh/plugins`, then oh-my-zsh's custom dir, and skips it if
absent. So any of these installs works — but only two of the four are packaged
on Debian.

| Plugin | macOS | Debian/Ubuntu |
|---|---|---|
| zsh-autosuggestions | `brew install zsh-autosuggestions` | `apt install zsh-autosuggestions` |
| zsh-syntax-highlighting | `brew install zsh-syntax-highlighting` | `apt install zsh-syntax-highlighting` |
| zsh-autocomplete | `brew install zsh-autocomplete` | **not packaged** — `git clone --depth 1 https://github.com/marlonrichert/zsh-autocomplete.git ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/plugins/zsh-autocomplete` |
| zsh-you-should-use | `brew install zsh-you-should-use` | **not packaged** — `git clone https://github.com/MichaelAquilina/zsh-you-should-use.git ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/plugins/zsh-you-should-use` |

### CLI tools

| Tool | macOS | Debian/Ubuntu | Gotcha |
|---|---|---|---|
| bat | `brew install bat` | `apt install bat` | **binary is `batcat`** |
| eza | `brew install eza` | `apt install eza` (24.04+), else [deb.gierens.de](https://github.com/eza-community/eza/blob/main/INSTALL.md) or `cargo install eza` | |
| fd | `brew install fd` | `apt install fd-find` | **binary is `fdfind`** |
| fzf | `brew install fzf` | `apt install fzf` | apt version is old; `source <(fzf --zsh)` needs ≥0.48 — git-clone install if it errors |
| ripgrep | `brew install ripgrep` | `apt install ripgrep` | |
| zoxide | `brew install zoxide` | `apt install zoxide` (24.04+), else `curl -sSfL https://raw.githubusercontent.com/ajeetdsouza/zoxide/main/install.sh \| sh` | |

`zshrc` detects `batcat`/`fdfind` and aliases them back to `bat`/`fd`, so the apt
names are handled — but only if the packages are actually installed. It will not
alias `cat` to something that doesn't exist.

### Font

JetBrainsMono Nerd Font. Without it, p10k's prompt and eza's `--icons` render as
tofu boxes.

- macOS: `brew install --cask font-jetbrains-mono-nerd-font`
- Linux: download `JetBrainsMono.zip` from
  [nerd-fonts releases](https://github.com/ryanoasis/nerd-fonts/releases/latest),
  unzip into `~/.local/share/fonts/`, then `fc-cache -fv`

Then set it as the terminal font — see `ghostty/SETUP.md`.

## Platform notes

Everything macOS-specific in these files is guarded by an existence check, so
none of it errors on Linux — it just doesn't apply:

- **Homebrew** — `zprofile` tries `/opt/homebrew`, `/usr/local`, and
  `/home/linuxbrew/.linuxbrew` in turn. This is what sets `$HOMEBREW_PREFIX`,
  which the plugin loader reads, so `zprofile` must load before `zshrc`.
- **Android SDK** — `~/Library/Android/sdk` on macOS, `~/Android/Sdk` on Linux.
  Both are checked; PATH entries are only added for subdirectories that exist.
- **conda, openjdk, amplify, console-ninja, antigravity, solana** — each added to
  PATH only if the directory is there.
- **`alias zshrc="code ~/.zshrc"`** assumes VS Code's `code` on PATH. Harmless if
  missing; the alias just fails when used.

## Verify

```bash
exec zsh                      # should start clean, no errors
alias cat && alias ls         # should point at bat/batcat and eza
echo $HOMEBREW_PREFIX         # set on macOS/Linuxbrew, empty otherwise
echo $FZF_DEFAULT_COMMAND     # should name fd or fdfind
```

Prompt should show powerlevel10k with glyphs. Tofu boxes mean the Nerd Font
isn't installed or isn't selected in the terminal.
